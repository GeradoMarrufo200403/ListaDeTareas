# Lista de tareas con cuentas de usuario

Aplicación de lista de tareas en la que cada persona tiene su propia cuenta. Monorepo con frontend (HTML, CSS y JS), API (Python + Flask) y base de datos (SQLite).

## Estructura

- `frontend/`: páginas que ve la persona.
- `backend/`: API en tres capas (`rutas`, `servicios`, `repositorios`) y `pruebas` con pytest.
- `database/`: esquema de la base de datos (el archivo `.db` local no se versiona).
- `backlog/`: idea, historias de usuario y especificaciones.
